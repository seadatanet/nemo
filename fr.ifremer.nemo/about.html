MENUS

1/Modèle/Ouvrir modèle : charge un modèle en mémoire à condition d'avoir déjà ouvert une campagne

2/Modèle/Enregistrer modèle : créé sur le disque un fichier modèle XML correspondant aux valeurs entrées dans les différentes étapes. N'est fonctionnel qu'après avoir validé les 4 premières étapes.

3/Quitter : ferme l'application après avoir demandé confirmation.

 

DESCRIPTION FICHIER

1/ Sélection "fichier" ou "dossier" en cochant ou non "Série temporelle".

2/ Bouton "Parcourir" et choisir un fichier/dossier.

3/ Si besoin, charger un modèle par le menu Modèle/Ouvrir un modèle et en choisissant le fichier XML du modèle correspondant à la campagne en cours.

4/ La zone Description de fichier s'affiche. Cliquer sur chaque section et modifier les valeurs.

5/ Pour indiquer un nombre de lignes, surligner avec la souris les lignes concernées dans la partie gauche de la fenêtre puis cliquer sur le bouton "injecter" de la section considérée.

6/ L'indicateur de fin de données peut être entré par l'utilisateur.

END sera traduit par NEMO en ^END$

EOF sera traduit par NEMO en ^$

Ces valeurs peuvent donc se retrouver après chargement d'un modèle.

7/ L'onglet "info" reprend les principales informations sur les fichiers campagne et modèle chargés.

8/ L'onglet "aide" affiche à chaque étape l'aide correspondante.

9/ Une fois les valeurs remplies, cliquer sur "valider" pour passer à l'étape suivante. Si des erreurs ont été commises, des messages apparaitront en rouge dans l'onglet "erreurs".

10/ Le bouton "reset" permet d'effacer toutes les valeurs de l'étape en cours.

 

DESCRIPTION CAMPAGNE

3 possibilités de remplissage de cette étape : entrer toutes les valeurs manuellement, interroger les Webservices ou charger un fichier XML.

1/ Manuellement : remplir les sections "référence", "localisation", "Sources des données" et "Commentaires éventuels". Pour la section "Centre d'archivage", choisir la confidentialité dans la combo list. Pour la section "types de données", un clic droit sur la table vide fait apparaitre un menu qui permet d'ajouter un nouveau type ("Sélection liste"), de déplacer ou de supprimer le type sélectionné. Ne pas tenter de cliquer gauche pour choisir une ligne puis de cliquer droit pour faire apparaitre le menu mais au contraire faire un clic droit directement. Sinon on passe en mode édition. La fenêtre de sélection des types de données permet d'effectuer une recherche à la fois sur le code et sur le nom du type.

2/ Webservices, bouton "initialisation serveur" : la fenêtre de sélection des campagnes permet d'effectuer une recherche à la fois sur le code et sur le nom de la campagne.

3/ Fichier XML, bouton "initialisation XML" : choisir un fichier XML de campagne.

 

DESCRIPTION DE STATION

Même principe que les étapes précédentes à la différence que certaines valeurs à injecter demandent des valeurs sur "ligne", "début" et "fin". Dans le cas d'un fichier campagne, toujours effectuer les injections sur la première station ! Dans tous les cas, la sélection devra se limiter à une ligne unique (date, heure, latitude, profondeur, etc.) sauf pour le "commentaire" où la possibilité de surligner plusieurs lignes est offerte.

Pour les formats d'heure, de date, de latitude et de longitude, on peut entrer ses propres formats.

 

FORMATS HEURE / DATE

yy ou yyyy : année exprimée sur 2 ou 4 digits

MM : mois exprimé sur 2 digits

dd : jour dans le mois exprimé sur 2 digits

hh : heure exprimée sur 2 digits

mm : minutes dans l’heure exprimées sur 2 digits

ss : secondes exprimées sur 2 digits

 

Les contraintes suivantes sont associées à ces formats :

 

Les valeurs sont complétées à gauche par un 0 si la valeur à afficher est inférieure à 10 (ex : année 2000 -> 00)

L’heure peut être absente

L’ordre entre la date et l’heure est libre (date heure, heure date)

Des caractères supplémentaires quelconques peuvent être insérés entre les différentes clés. Ceux-ci seront attendus tel quel en entrée et rendus tel quel en sortie

            Exemples:

yyy/MM/dd hh:mm:ss ==> 1986/07/10 09:23:10

hh:mm ==> 09:23

yy-MM-dd ==> 86-07-10

 

FORMATS LATITUDE / LONGITUDE

N : exprime un hémisphère. Sa valeur devra être égale à N ou S dans le cas des latitudes, et W ou E dans le cas des longitudes

DDD ou DD : Nombre de degrés. Le nombre de D doit être 3 dans le cas des longitudes et 2 dans le cas des latitudes

DDD.ddd ou DD.ddd : Degrés en valeur décimales. Le nombre de D doit être 3 dans le cas des longitudes et 2 dans le cas des latitudes. Le nombre de caractères « d » exprime la précision attendue

MM : Nombre entier de minutes

MM.mm : Minutes en valeur décimale. Le nombre de caractères « m » exprime la précision attendue

SS : valeur entière des secondes

+DDD.ddd

 

Les contraintes suivantes sont associées à ces formats :

 

Les valeurs sont complétées à gauche par un espace si la valeur entière à afficher n’occupe pas le nombre de caractères attendus

L’indicateur d’hémisphère peut se trouver avant ou après la valeur numérique

Dans le cas où les degrés sont exprimés en valeurs décimales, aucune minute n’est attendue

Dans le cas où les minutes sont exprimées en valeurs décimales, aucune seconde n’est attendue

Des caractères supplémentaires quelconques peuvent être insérés entre les différentes clés. Ceux-ci seront attendus tel quel en entrée et rendus tel quel en sortie

Exemples :

NDDD MM.mm ==> W123 10.25

DDD MM SS N ==> 123 10 30 W

 

DESCRIPTION DONNEES

Même principe que pour les types de données : on ajoute ici les paramètres mesurés.

Dans le cas d'une série temporelle :

*les paramètres DATE, YEAR, MONTH, DAYX, TIME sont rajoutés automatiquement à la génération donc attention à ne pas les ajouter manuellement.

*on peut choisir si le calcul des dates/heures est basé sur les dates/heures entrées à l'étape Station et la fréquence d'échantillonnage ou si les informations sont présentes au sein de la ligne des données (auquel cas préciser le format).

 

CONVERSION

Choisir le format de sortie. On peut générer les deux formats à la suite sans devoir revalider toutes les étapes.
