# Documentation NEMO

Ce dossier regroupe la documentation technique et fonctionnelle du projet NEMO.

## Manuel utilisateur

* `sdn_Nemo_UserManual.docx` : source Word du manuel utilisateur (version courante 2.2.0).
* `sdn_Nemo_UserManual.pdf` : version PDF exportée, embarquée dans les ressources de l'application (`fr.ifremer.nemo/resources/sdn_Nemo_UserManual.pdf`).

## Documentation technique

* `NEMO_documentation_technique.odt` : document d'architecture et de conception technique de NEMO.
* `NEMO_documentation_annexe.ods` : annexes techniques et contextes de conversion.
* `illustrations.odg` : schémas et illustrations techniques.
* `RapportInterventionOPCoach.pdf` : rapport d'intervention technique historique.

Pour les procédures de build et de livraison, se référer au document `RELEASE.md` à la racine du dépôt.
